# クナイ修行

ニコ生ゲーム(ランキングモード)向けの自作ゲームです。「自作ゲームパーティー2026秋」の『ノンジャンル』部門向けの候補です(同じ部門の「ころころ玉入れ」とどちらかを選んで応募します)。

## あそびかた

- **タップでクナイを投げます。** クナイは回っている丸太のいちばん下に刺さります。
- **すでに刺さっているクナイに当たると「カキーン!」で失敗**です。その修行を最初からやり直し、その挑戦で得た点は没収されます。
- 決められた本数を全部刺すと**修行クリア**。丸太が割れて次の修行へ進みます。ミスなしでクリアすると「一発クリア」ボーナスです。
- 丸太の回り方は修行ごとに変わります(一定 / 急な逆回転 / 緩急 / 止まって急発進)。修行が進むほど速くなり、最初から刺さっている黒いクナイも増えます。
- **5番目ごとに「師匠の丸太」**が出ます。回り方が不規則で、刺す本数も多いです。
- 丸太のふちの**小判**の位置に刺すとボーナスです(一度とった小判は、やり直しても出ません)。
- ミスなしで刺し続けるほど倍率が上がります(最大×3)。カキーンで倍率は元に戻ります。
- **ラスト10秒は得点2倍**です。

| | 点数 |
| --- | --- |
| クナイ1本 | 100 × れんぞく倍率(最大×3) |
| 小判 | 500 |
| 修行クリア | 500 × 修行の番号 |
| 一発クリア | さらに +1000 |

丸太の回り方、黒いクナイと小判の位置は共通乱数(`randomSeed`)から作るので、同じ回の参加者は全員同じ修行で競います。

## 開発

```bash
npm install          # 依存を入れてビルド
npm start            # サンドボックスで起動
npm test             # headless-akashic で最後まで遊ぶテスト
npm run assets       # 画像と効果音を作り直す
npm run export-zip   # 投稿用の game.zip を作る (ネットにつながったPCで)
```

- 画像は `tools/gen-images.js`、音は `tools/gen-audio.py` で作っています。外部素材は使っていないので、権利表記は不要です。忍者たぬきは「おいもチキン」のたぬきに覆面とマフラーを描き足しています。
- 解像度 1280x720 / 30fps / 希望制限時間 75秒(説明4秒 + プレイ61秒 + 結果)。
