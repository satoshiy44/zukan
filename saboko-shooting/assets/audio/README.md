# さぼこしゅーてぃんぐのBGM置き場

ここに音楽ファイルを置いて、次を実行するとBGMが差し替わります。

```
node saboko-shooting/tools/build-audio.mjs
node saboko-shooting/tools/bundle.mjs
```

- ファイル名は `bgm.mp3` が基本ですが、**曲が1つだけなら曲名のままでも使われます**
- 拡張子は `.mp3` `.m4a` `.ogg` `.wav`
- 何も置かなければ、`audio.js` が合成したループ（Aマイナーの押し続ける感じ）を鳴らします
- 目安は30秒〜1分半のループで**3MB以内**。超えるとビルド時に警告が出ます

音量は `audio.js` の `FILE_BGM_VOLUME`（初期値 0.16）です。

スイカゲームのBGM（`../../assets/audio/`）とは別管理なので、
こちらだけ違う曲にできます。

## 効果音とうなり声について

撃つ音・うなり声・爆発などはすべて WebAudio で合成しています。
撃つ音は毎秒5発鳴るのでファイル再生には向かず、うなり声は毎回
音程と揺れを変えたいためです。差し替えの対象にはしていません。

うなり声の質感は `audio.js` の `groanAt()` で変えられます。
`base`（基本の高さ）と `lfo.frequency`（揺れの速さ）が効きます。
