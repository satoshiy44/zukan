# ひっこぬけ！おいもチキン(略: いもチキ)

ニコ生ゲーム(ランキングモード)向けの自作ゲームです。「自作ゲームパーティー2026秋」への応募を想定しています。

## あそびかた

前半と後半の2部構成です(希望制限時間は90秒)。

### 前半「いもほり」(約35秒)
- 画面を**長押し**すると、たぬきがつるを引っぱり、さつまいもが抜けてきます。抜けたいもは「手もと」にたまります。
- **指をはなすと、手もとのいもがかごに入ります**(ゲット!)。
- 「ピン」メーターが満タンになって**ブチッと切れると、手もとのいもはパー**です。メーターが赤くなると、心臓の音と画面の点滅で知らせます。
- **1回の長押しで4個以上続けて抜くと、いもがランクアップ**します(ふつう→大きい→金)。欲張るほど良いいもが手に入ります。
- つるを最後まで抜くと、おまけで大きいいも。一度もはなさずに抜く「一本釣り」なら、おまけで金のいもがもらえます。
- たまに「**金のつる**」が出ます。いもが全部 金のいもですが、つるが固いです。

### 後半「やきいも屋台」(約35秒)
- かごのいもを、高く売れるもの(金→大→ふつう)から順に石焼き窯で焼きます。
- 焼き加減のメーターが「なま→ほくほく→**極上**→ほくほく→こげ」と進むので、**ちょうどいいところでタップ**して売ります。
- 針の動き方はお客さんごとにちがいます。
  - **くまさん「のんびり」**:ゆっくり進むが、途中で急に強火になって針が飛ぶ。
  - **うさぎさん「せっかち」**:速い。途中で一瞬止まって、そのあと一気に進む。
  - **きつねさん「きまぐれ」**:速くなったり遅くなったり、波のように緩急がつく。
- いいいもほど焼けるのが速くなります(大きいいも×1.1、金のいも×1.25)。
- お客さんの順番と動き方は共通乱数で決まるので、同じ回の参加者は全員同じお客さんに売ります。
- 極上は×3、ほくほくは×2、なまは×0.3、こげは0点です。
- うまく焼き続けると「常連さん」が増えて、値段が最大×2になります。失敗すると常連さんは元に戻ります。
- **最後の8秒は「閉店まぎわの大行列」で値段2倍**です。
- 時間内に売れるのは30個くらいです。前半でたくさん集めても全部は売れないので、**後半の焼きの腕で逆転できます**。売れ残りは1個20点の安売りになります。

| いも | 前半(かごに入れたとき) | 後半の売値(×焼き加減×常連さん) |
| --- | --- | --- |
| ふつうのいも | 10 | 50 |
| 大きいいも | 30 | 150 |
| 金のいも | 100 | 400 |

つるの形(長さ、いも、石、かたさ)はランキングの共通乱数(`randomSeed`)から作ります。同じ回の参加者は、全員同じつるで競います。

## 開発

```bash
npm install          # 依存を入れてビルド
npm start            # サンドボックスで起動 (http://localhost:3000)
npm run build        # TypeScript をビルド
npm run assets       # 画像と効果音を作り直す (tools/ の生成スクリプト)
npm run export-zip   # 投稿用の game.zip を作る (akashic export zip --nicolive)
```

`--nicolive` はランタイムのバージョンをネットから取ってきます。取れない環境では、game.json の `environment` に一時的に `"akashic-runtime": { "version": "~3.13.4-0", "flavor": "-canvas" }` を書いてから実行すると、取得をとばせます(値は https://github.com/akashic-games/akashic-runtime-version-table の versions.json の latest["3"])。

## 仕様メモ

- 解像度 1280x720 / 30fps / `supportedModes: ["ranking"]` / 希望制限時間 90秒
- 時間配分は、説明とカウントダウン 5秒、前半(プレイ時間の50%)、切りかえ 4秒、後半、結果表示 約11秒です。制限時間の約10秒前までに結果表示を終えます。
- スコアは `g.game.vars.gameState.score` に、得点が入るたびに書き込みます。
- 展開後のサイズは約1MB です(上限は10MB)。
