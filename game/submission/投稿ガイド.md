## おすすめの部門

**『一発逆転』部門**をおすすめします。『秋の季節ネタ』に出すこともできます。

- 一発逆転部門の審査基準は「最後の1秒まで勝敗がわからない」です。このゲームの「ラスト15秒の大株(得点2倍、金のいも3個)」は、ちょうどこれを狙った仕組みです。ブチッと切れるかどうかのチキンレースにも、ギャンブル性があります。
- 秋部門はテーマが分かりやすいぶん、応募が多くなりそうです。一発逆転部門なら「秋らしい見た目」が他の作品との違いになります。
- 過去の受賞作は、部門のお題にはっきり沿った作品が多い傾向です。部門を決めたら、説明文の1行目でお題に合っていることをアピールしてください。

## 投稿手順
1. インターネットにつながった PC で、`game/` フォルダを開いて `npm install` し、`npm run export-zip` を実行して `game.zip` を作ります。
2. https://namagame.coe.nicovideo.jp/games/new を開き、ニコニコアカウントでログインします。
3. 「ゲームファイル」欄に `game.zip` を指定します。アイコンには `submission/icon.png`(320x320)を使います。
4. タイトルと説明文に、下のテンプレートを貼ります。**公式が指定するハッシュタグを必ず入れてください。**
5. いったん**非公開**で投稿し、自分の放送で起動して、PC・iPhone・Android それぞれで動くか確認します。そのあと公開します。

## 公開後にやること(起動数を増やす)
過去回では、審査で起動者数・起動回数・起動時間も参考にされていました。そこで次のことをすると効果的です。
- 自分の放送で遊んでみせて、プレイ動画をニコ動に投稿する。スコア自慢の動画は、えげぶろの伸び方と同じパターンです。
- X で「○万点出た」「大株ぶっこ抜き成功」のスクショ報告を呼びかける。結果画面の**称号**は、スクショで共有されやすいように入れてあります。
- 配信者に遊んでもらう。短い略称(「いもチキ」)は、放送タイトルに入れやすいようにしてあります。
- 反応を見て「かんたん版」を出すのも手です。えげぶろのSG版のように、救済版で遊ぶ人の層が広がった例があります。ただし応募は1部門1作品なので、同じ部門に2作出さないよう注意してください。
