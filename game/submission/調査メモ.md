# 調査メモ: 採用される・人気が出るニコ生ランキングゲーム

2026/9/30 に Web 検索で調べました。blog.nicovideo.jp などは直接読めなかったため、検索結果の要約も使っています。「未確認」と書いたものは一次情報で確かめていません。

## 人気作の分析

### えげつないブロック(えげぶろ)
- 2026春の自作ゲームパーティー、ノンジャンル部門の最優秀賞です。
- 6×6×6 のキューブで遊ぶ3D麻雀ソリティアです。
- 全部消すと大量加点、さらに残り秒数でも加点されます。そのため点数が大きく二極化し、順位発表が盛り上がります。
- 「えげぶろ」という略称が放送タイトルに定着し、専用の放送枠やスコア動画が生まれました。
- 救済版の「SG版」で、遊ぶ人の層が広がりました。

### ケーキカット
- 均等に切り分けるゲームです。ルールの説明がほとんど要りません。
- 切った結果がそのまま画面に出るので、コメントでツッコみやすいです。
- 点数は均等さの4乗で決まるため、わずかな差で大きく点が変わります。

### 過去の受賞作
- スイカ割り、ひめスロ、パンツを汚すな、将棋サッカー、テストを返す、などがあります。
- いずれも部門のお題にはっきり沿っています。
- バカゲー、ギャンブル、スロットといったネタ性が強い作品が多いです。

## 人気が出る要素と、このゲームでの対応

| 要素 | いもチキでの対応 |
| --- | --- |
| 説明不要のルール | 長押しで引っぱり、はなしてゆるめる。操作はこれだけ |
| 1分前後で終わる | 希望制限時間は75秒(プレイ60秒) |
| 点差が大きく開く、一発逆転がある | ラスト大株(×2、金のいも3個)、連続倍率(最大×3)、一本釣り |
| 運と実力が両方ある | つるは全員共通。差がつくのは、どこでゆるめるかの判断と反応の速さ |
| 見ているだけで面白い | ブチッ!としりもちをつくたぬき、いもが飛んでいく、石に怒り顔 |
| 覚えやすい名前・略称 | 「おいもチキン」「いもチキ」 |
| かわいい見た目 | 顔つきのおいも、はちまき姿のたぬき |
| やり込みと共有 | 称号(見習い→神さま)、一本釣りの回数、大株を抜けたかどうか |
| 部門のお題に合っている | 秋(芋掘り・紅葉)と一発逆転(ラスト大株)の両方 |

## 技術仕様(公式テンプレートとドキュメントで確認済み)
- `environment.nicolive.supportedModes: ["ranking"]` を指定します。
- 制限時間 `totalTimeLimit` の希望値は20〜200秒です。指定しないと約80秒になります。実際の値は起動時のセッションパラメータから読みます。
- 結果の表示は、制限時間の約10秒前までに終えるのが推奨です。
- スコアは `g.game.vars.gameState.score` に入れます。0以上の整数で、常に更新しておく必要があります。99999以下が推奨です。
- 参加者全員で同じ条件にしたい部分には、共通乱数(`randomSeed` から作る `param.random`)を使います。
- 投稿できる容量は、zip を展開して10MB以下です。game.json は100KB以下です。
- 出力は `akashic export zip --nicolive` です。投稿先は https://namagame.coe.nicovideo.jp/games/new です。
- 2026/2/25 から、自作ゲームはランキング形式のものしか投稿・プレイできなくなりました。
