# たきびでポン！やきいもパズル

ニコ生ゲーム(ランキングモード)向けの自作パズルゲームです。「自作ゲームパーティー2026秋」の『秋の季節ネタ』部門への応募を想定しています。

## あそびかた

- 同じ種類の葉っぱ(もみじ、いちょう、どんぐり、ぶどう)が**2つ以上つながっているところをタップ**すると消えます。消した葉っぱはたき火に飛んでいきます。
- 消えたところには上の葉っぱが落ちてきます。空いた列は左につまります(さめがめと同じルール)。
- 点数は **消した数×消した数×10**。いっぺんにたくさん消すほど、ぐーんと増えます。
- 盤面のやきいも(1盤面に3個)は、**いちばん下まで落とすとたき火に入って +1000点**です。
- 消せる所がなくなると盤面は終わりです。残りの数に応じてボーナスが入り、次の盤面に進みます。
  - 残り0: **ぜんぶたき火!! +5000**
  - 残り3以下: +2000
  - 残り6以下: +800
- **ラスト10秒は「たき火フィーバー」**で、得点が2倍になります。

盤面はランキングの共通乱数(`randomSeed`)から作ります。同じ回の参加者は、全員同じ盤面で競います。

## 難しさの目安
11列×5段(1マス96px)の盤面を、パソコンで150回シミュレーションしました。
- なんとなく消すと、残りは平均11個くらいで、全消しはほぼ出ません。
- 先を読んで消すと、全消しが約22%、残り3以下が約63%になります。

考えるほど点が伸びるので、ランキングで実力差が出ます。

## 開発

```bash
npm install          # 依存を入れてビルド
npm start            # サンドボックスで起動
npm run build        # TypeScript をビルド
npm test             # headless-akashic で最後まで遊ぶテスト
npm run assets       # 画像と効果音を作り直す
npm run export-zip   # 投稿用の game.zip を作る (ネットにつながったPCで)
```

- 画像は `tools/gen-images.js`、音は `tools/gen-audio.py` で作っています。外部素材は使っていないので、権利表記は不要です。
- 解像度 1280x720 / 30fps / 希望制限時間 75秒(説明4秒 + プレイ60秒 + 結果)です。
- 展開後のサイズは約0.7MB です(上限は10MB)。
