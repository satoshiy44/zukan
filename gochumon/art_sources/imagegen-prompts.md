# 画像生成プロンプト

このゲームの背景・人物・紋章は、Codex内蔵の画像生成機能で作成したオリジナル素材です。
既存作品のキャラクター、ロゴ、固有の意匠は使用していません。

## 背景

```text
Use case: stylized-concept
Asset type: 1280x720 game background for a Japanese casual ordering game
Primary request: Create an original, richly illustrated old-European cafe interior with a refined vintage mystery storybook atmosphere. No characters and no interface elements.
Scene/backdrop: late-19th-century-inspired cafe, carved dark wood counter, arched windows, framed botanical sketches, brass lamps, tiled floor, shelves with teapots and jars, layered depth but a clear open center for gameplay UI.
Style/medium: hand-inked 2D illustration with subtle watercolor and gouache textures, expressive slightly irregular outlines, elegant storybook animation background, polished game art. Original visual language, not a copy of any existing franchise.
Composition/framing: wide 16:9, straight-on, central playable area uncluttered, darker perimeter and brighter central counter area.
Lighting/mood: warm amber lamplight, cozy, clever, whimsical, lightly mysterious.
Color palette: sepia parchment, walnut brown, muted burgundy, antique teal, brass gold, cream.
Constraints: no people, no food, no text, no letters, no logos, no watermark, no recognizable copyrighted characters or franchise-specific symbols.
```

## お客さん

```text
Use case: illustration-story
Asset type: transparent character sheet for a 2D ordering game
Primary request: Create three distinct original cafe customers standing full-body, arranged left-to-right with generous separation: (1) a cheerful elderly woman carrying a tiny handbag, (2) a serious young bookkeeper with round spectacles and a long coat, (3) an upbeat traveling musician with a scarf and violin case. They are customers, not detectives.
Style/medium: refined hand-inked storybook animation character art with subtle watercolor and gouache texture, slightly exaggerated proportions, expressive simple faces, elegant late-19th-century European clothing, warm whimsical mystery atmosphere. Entirely original visual language, not a copy of any existing franchise.
Composition/framing: front-facing, full body, consistent scale, each figure isolated and not touching, all feet visible, no cast shadows beyond a faint grounding wash.
Color palette: muted burgundy, antique teal, ochre, cream, walnut brown, charcoal ink.
Lighting/mood: warm and friendly.
Constraints: transparent background, no text, no logos, no hats resembling famous puzzle-game characters, no recognizable copyrighted characters, exactly three people, no overlap.
```

## ロゴ用紋章

```text
Use case: icon-symbol
Asset type: transparent decorative emblem for a Japanese cafe ordering game logo
Primary request: Design an original ornate late-19th-century cafe crest built around a polished brass serving cloche, a tiny sparkling coin, curling botanical flourishes, and a blank cream ribbon banner beneath it.
Style/medium: hand-inked storybook illustration with subtle watercolor and gouache texture, elegant Art Nouveau ornament, warm whimsical mystery atmosphere, polished game logo asset. Entirely original and not based on any existing franchise.
Composition/framing: centered, symmetrical, bold readable silhouette, generous transparent margin, isolated emblem.
Color palette: antique brass gold, deep burgundy, antique teal, cream parchment, walnut outline.
Constraints: transparent background, no words, no letters, no numbers, no logos, no watermark, no characters, no recognizable copyrighted symbols.
```
