# 音声ファイルの置き場所

ここにファイルを置いて、ビルドコマンドを走らせるだけです。

```
node tools/build-audio.mjs
```

置いていないものは、`audio.js` が合成音で代わりに鳴らします。
1つも置かなくても音は出るので、BGMだけ差し替える、といった使い方ができます。

## ファイル名

名前は固定です。拡張子は `.mp3` `.m4a` `.ogg` `.wav` のどれでも構いません。
ただしBGMだけは、`bgm.*` が無くて曲が1つだけ置いてあれば、曲名のままでも使われます。

| ファイル名 | 鳴る場面 |
|---|---|
| `bgm.mp3` | BGM。自動でループ再生されます |
| `drop.mp3` | さぼこを落としたとき |
| `merge.mp3` | 合体したとき |
| `clear.mp3` | 最大どうしを消したとき |
| `gameover.mp3` | ゲームオーバー |

## 長さと容量の目安

| | 目安 |
|---|---|
| BGM | 30秒〜1分のループ。**3MB以内**を推奨 |
| 効果音 | 1秒以内・数十KB |

配布用の1枚HTML（`dist/saboko-drop.html`）に埋め込む都合で、
音声はファイルサイズの約1.33倍になって入ります。大きすぎるとビルド時に警告が出ます。

音楽ファイルにはアルバムアートが埋まっていることがあり、それだけで数MBを占めます。
ビットレートを落としつつ画像を外すと、音質をほとんど変えずに小さくできます。

BGMは**始めと終わりが自然につながる素材**にすると、ループの継ぎ目が目立ちません。

## 音量

`audio.js` の `FILE_BGM_VOLUME`（初期値 0.16）で調整できます。数字を上げると大きくなります。
効果音は `sfxGain.gain.value`（初期値 0.5）です。

## 合体音について

合体音は段階が上がるほど少しずつ高く再生されます（再生速度で調整）。
1種類のファイルを置くだけで、育っていく感じが出るようにしてあります。
