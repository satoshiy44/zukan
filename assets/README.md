# 素材の置き場所

このフォルダに `saboko_1.png` 〜 `saboko_8.png` を置くと、ゲームが自動で読み込みます。
ファイルが無い段階では、コード側が仮の丸（色＋顔＋段階番号）を描くので、素材が揃う前でも遊べます。

## 仕様

| 項目 | 内容 |
|---|---|
| ファイル名 | `saboko_1.png` 〜 `saboko_8.png`（1が最小、8が最大） |
| 形式 | PNG（背景透過） |
| サイズ | 正方形。512×512 か 1024×1024 の1サイズでOK（縮小はコード側でやります） |
| 配置 | **キャラが正方形にちょうど内接するように**中央配置 |

## 配置についての注意

当たり判定は「画像の正方形にぴったり収まる円」です。
キャラの周りに余白があると、見た目より当たり判定が大きくなって
「触れてないのに合体した」ように見えるので、余白は詰めてください。

画像は物理の回転に合わせてクルクル回ります。上下がはっきりある絵ほど回転が目立つので、
丸っこいシルエットにするか、回転が気にならないデザインにすると馴染みます。
