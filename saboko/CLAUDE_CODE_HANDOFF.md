# Claude Code 引き継ぎ書：にげろさぼこ！

## 1. 作業対象

- プロジェクト名：にげろさぼこ！
- 種別：ニコニコ生放送「ニコ生ゲーム」ランキングモード専用
- エンジン：Akashic Engine v3
- 言語：TypeScript
- 解像度：1280×720
- フレームレート：30fps
- プロジェクトルート：このファイルがあるディレクトリ
- ローカル確認URL：`http://localhost:3301/public/sandbox/`

## 2. 現在のゲーム内容

かぼちゃ衣装の女の子「さぼこ」が、猫帽子をかぶった白タイツの男「白凸男」から逃げる
横スクロールのジャンプゲーム。短いタップで小ジャンプ、長押しで大ジャンプする。

- キャンディやペロペロキャンディを集めて得点する。
- 白凸男との距離が近いほど危険倍率が上がり、獲得点が最大5倍になる。
- 障害物、明確な穴、ジャンプで選ぶ段差式の上ルートがある。
- 穴へ落ちてもゲーム終了にはならず、減点後に上から点滅して復帰する。
- 障害物は衝突しても消えない。
- 白凸男は「本気・疲れ・通常」を繰り返して追跡速度が変化する。
- 白凸男は3秒予告後に突進し、ジャンプで回避すると得点になる。
- 突進した白凸男は右端へ走り抜けて消え、左端から追跡を再開する。
- この走り抜け突進は、通常80秒の1プレイ中に最低4回完走する。
- カラフルな小さい女の子が右から走ってきて、白凸男を攻撃する。
- 小さい女の子の登場時には「にげろさぼこ！」の吹き出し、中央表示、効果音が出る。
- さぼこは約10秒ごとに後ろを振り向き、頭の後ろに汗エフェクトが出る。
- 白凸男は約30秒ごとに台詞の吹き出しを出す。
- 残り20秒からラッシュ演出と専用BGMに変わる。
- 最後はニコ生側が順位を表示するため、ゲーム内結果画面は作らない。

## 4. 直近の修正

1. 白凸男を少し小さくした。
2. 白凸男の突進を、プレイヤーの前まで来て止まる動きではなく、右端まで走り抜ける動きにした。
3. 白凸男が右端へ消えたあと、約1.2秒後に左端から通常追跡を再開するようにした。
4. 突進完走回数を数え、4回未満では短い間隔で次の突進を予約するようにした。
5. カラフルな女の子の登場時に「にげろさぼこ！」の吹き出しと効果音を追加した。
6. 坂を廃止し、上ルートはジャンプで乗る段差式の足場に変更した。
7. 地面の高さが突然変わる処理をなくし、落下する場所を警告付きの明確な穴だけにした。

## 5. 必ず守る技術条件

- スコアは整数で `g.game.vars.gameState.score` に保持し、変化するたび更新する。
- 制限時間は `param.sessionParameter.totalTimeLimit` を優先し、未指定時は80秒。
- `game.json` の推奨制限時間も80秒。
- 乱数は `param.random` のみを使い、`Math.random()`は禁止。
- `lib` はES5。`for...of`、`Map`、`Array.prototype.find`などを使わない。
- 1行140文字以内を維持する。
- BGMの `systemId` は `music`、ループあり。効果音は `sound`。
- 終了5秒前にはゲームの動きと演出を終える。
- 画面上部約18％と下部約7％には重要な操作や表示を置かない。
- タップ対象は120px四方以上、重要文字は40px以上を目安にする。
- 投稿ZIPには次のランタイム設定を維持する。

```json
"akashic-runtime": {
  "version": "~3.13.4-0",
  "flavor": "-canvas"
}
```

```sh
pnpm install
```


```sh

```

```sh

```

または：

```sh
npx akashic export zip -o game.zip --nicolive -f
```

## 9. 変更時の注意

- `src/main.ts`には、突進・通常追跡・小さい女の子の攻撃が同時に動く状態がある。
- 小さい女の子が突進中の白凸男に当たると突進が中断される場合がある。
- 中断時は4回完走に数えず、短い時間で再予約する実装になっている。
- 白凸男が右端へ抜けた時だけ完走回数を加算する。
- 4回未満の間は突進間隔を短くし、4回達成後は通常のランダム間隔へ戻す。
- キャラクターを再生成する際も、女性の顔写真を別人風に変えない。
- 「レイトン教授風」など既存作品そのものの画風コピーは避け、レトロな手描きミステリー調など一般表現へ置き換える。
