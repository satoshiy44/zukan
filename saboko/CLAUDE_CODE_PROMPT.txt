このフォルダは、Akashic Engine v3／TypeScriptで作成したニコ生ランキングゲーム
「にげろさぼこ！」のプロジェクトです。

最初に CLAUDE_CODE_HANDOFF.md、README.md、投稿用説明文.txt、game.json、src/main.ts、
spec/testSpec.ts を順番に読み、現在の仕様と直近の変更を把握してください。

重要事項：
- 既存のゲームと素材を引き継ぎ、別プロジェクトを作り直さないでください。
- ユーザーの新しい依頼が来るまでは、勝手に仕様変更や大規模なデザイン変更をしないでください。
- 変更時は、Akashic Engine v3、1280×720、30fps、ランキング専用の条件を維持してください。
- スコアは整数で g.game.vars.gameState.score に入れ、変化するたび更新してください。
- 乱数は param.random だけを使い、Math.random は使わないでください。
- ES5で使えない構文やAPIを使わず、1行140文字以内にしてください。
- 画像・音声を追加したら npx akashic scan asset で game.json に登録してください。
- 音声は .ogg と .aac の両方を用意してください。
- 女性キャラクターの顔と髪は art_sources/hero-face-reference.png の本人らしさを保ってください。
- 白凸男は幽霊ではなく白タイツの人間で、水色ハチワレ猫帽子と黒いもやもやが特徴です。
- カラフルな小さい女の子は右から走ってきて「にげろさぼこ！」と叫び、白凸男を攻撃します。
- 白凸男は最低4回、右端まで突進して消え、その後左端から追跡を再開します。
- 坂は使わず、上ルートはジャンプで乗る段差式にしてください。
- 不明瞭な落下を作らず、穴は床が明確に途切れ、事前警告がある場所だけにしてください。

作業前に既存の変更を消さないようファイル状態を確認してください。変更後は必ず次を実行してください。

pnpm run lint
pnpm run build
pnpm test --runInBand

可能なら http://localhost:3301/public/sandbox/ でも実際の表示と操作を確認してください。
完了報告は日本語で、変更点、テスト結果、確認URL、更新したファイルを短くまとめてください。
