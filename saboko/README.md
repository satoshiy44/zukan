# にげろさぼこ！

Akashic Engine v3で作った、ニコニコ生放送「ニコ生ゲーム」ランキングモード専用ゲームです。

## 遊び方

- タップでジャンプ、長押しで高くジャンプ、空中でもう1回タップで2段ジャンプ。
- お菓子(キャンディ100・ペロペロ300・大アメ1000)を集める。10コンボごとに×0.5ずつ上がる(最大×3)。
- 白凸男が近いほど得点が×2・×3。上の「白凸男」メーターが近さ。
- 白凸男は「本気・つかれた・ふつう」をくり返して近づいたり離れたりする。追いつかれると-500。
- 走りはじめて10・24・38・52秒に「いくぞー！」→3秒後に右まで突進(1プレイ最低4回)。ジャンプでよけると+1000。
- 右から来るカラフルな女の子が白凸男をこうげき(+300、白凸男が離れる)。
- 障害物(墓石・木の根・かぼちゃの山)、ジャンプするとぶつかるコウモリ、看板つきの穴、段差の足場。
- 障害物どうしは、その時の速さでジャンプして着地できる間をかならずあける。突進の前後には障害物を置かない。
- 走りはじめて17・31・45秒ごろに、上の道(長い足場)と下の道(地面)にわかれる。白タイツはランダムでどちらかに入り(入り口の看板と吹き出しで予告)、同じ道だとダッシュしてきてつかまる(-500)。ちがう道なら+500。
- 10秒に1回、走りながら首だけふり返り、頭のうしろに汗がとぶ。
- ラスト20秒は赤い夜と速いBGMで白凸男がもうつい。終わる5秒前に動きを止めて「おしまい！」を出す。
- 制限時間は totalTimeLimit(なければ80秒)。最初の4秒はカウントダウン。

## 素材の生成

キャラ・背景は `pnpm run assets`、エフェクトの画像は `node tools/gen-fx.js`、効果音とBGMは `python3 tools/gen-audio.py` で作ります。
女の子の顔と髪は、制作者から提供された写真をそのまま合成しています。

## 投稿用ZIPの作り方

`game.json` には次の設定が入っています。

```json
"akashic-runtime": {
  "version": "~3.13.4-0",
  "flavor": "-canvas"
}
```

次のコマンドで投稿用ZIPを作ります。

```sh
npx akashic export zip -o game.zip --nicolive -f
```

このプロジェクトでは `pnpm run export-zip` でも同じ内容を書き出せます。

## 主なファイル

- `src/main.ts`: ゲーム本体
- `game.json`: 画面・素材・ニコ生ランキング設定
- `tools/make_assets.py`: 画像・音声生成処理
- `tools/make_assets.mjs`: 生成処理の起動スクリプト
- `icon.png`: 投稿用アイコン（256×256）
- `promo.png`: 紹介画像（1280×720）
- `投稿用説明文.txt`: 投稿ページ用の説明文
