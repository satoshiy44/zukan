# さぼこウェーブ

前へ走りながら、奥から迫ってくるさぼこの群れを撃ち倒すシューティングです。
`index.html` をブラウザで開くだけで動きます（サーバ不要・オフライン可）。

## 遊び方

- 左右に動かすだけ。**弾は自動で出ます**（`←` `→` でも操作可）
- **ゲート**：左右に分かれた強化パネル。通ったほうの効果が乗ります。赤は悪い効果
- **バレル**：数字が残り体力。壊せないままぶつかるとダメージ
- 敵は**横にずれていれば脇を通り抜ける**ので、避ける操作に意味があります
- **オムライス**：体力が減っていると流れてきます。撃つと回復
- 一定時間ごとにボス。最後は犬

## 3Dライブラリは使っていません

奥行きは Canvas 2D の計算だけで出しています。世界の座標は `x`（左右）と
`z`（奥行き）の2つだけ持ち、描くときに

```
縮尺 s = FOCAL / (FOCAL + z)
```

を掛けて位置と大きさをまとめて遠近に変換します。あとは `z` の大きい順
（奥から手前）に描けば重なりも正しくなります。敵・バレル・ゲートは
毎フレームまとめて `z` で並べ替えています。

`FOCAL` を小さくすると遠近が強くつきますが、効かせすぎると奥の敵が
地平線近くの細い帯に固まって「迫ってくる」感じが消えます。
`FOCAL` を大きめに取り、そのぶん湧く距離（`ZFAR`）を近くするのがコツです。

## ファイル構成

```
index.html                  画面
style.css                   見た目
game.js                     ゲーム本体
audio.js                    効果音・うなり声・合成BGM（すべてWebAudio）
assets/sprites.js           さぼこのスプライト（自動生成）
assets/audio/               BGMを置く場所（→ assets/audio/README.md）
assets/sounds.js            BGMを埋め込んだもの（自動生成）
tools/build-sprites.mjs     ../../assets/src の画像から sprites.js を作る
tools/build-audio.mjs       assets/audio の音源から sounds.js を作る
tools/bundle.mjs            全部を1枚のHTMLにまとめる
```

## 素材

スイカゲームと**同じ画像を共用**しています（`../assets/src/saboko_*.PNG`）。
画像を差し替えたら、リポジトリのルートで次を実行してください。

```
npm run wave:build
```

## 音

BGMは `assets/audio/` に曲を置いて `npm run wave:audio` を実行すると差し替わります。
置かなければ `audio.js` が合成したループ（Aマイナーの押し続ける感じ）を鳴らします。
スイカゲームとは別管理なので、こちらだけ違う曲にできます。

効果音とうなり声はすべてWebAudioで合成しています。撃つ音は毎秒5発鳴るので
ファイル再生には向かず、うなり声は毎回音程と揺れを変えたいためです。

うなり声は、低いノコギリ波をゆっくり下げつつLFOで揺らし、息づかいのノイズを
重ねて作っています。**一番近い敵との距離で音量が変わり、その敵の左右位置から
聞こえます**。群れが湧いたときは4声重ねています。質感は `audio.js` の
`groanAt()` の `base`（基本の高さ）と `lfo.frequency`（揺れの速さ）で変えられます。

## 敵の割り当て

| 役 | 画像 |
|---|---|
| 雑魚 | 1 指差し / 2 パジャマ / 9 制服 / 3 頭巾 |
| 速い | 5 顔アップ |
| 硬い | 4 ギター |
| すごく硬い | 6 鼻アップ |
| 回復 | 7 オムライス |
| ボス | 8 自撮り → 10 夜ふかし → 11 就寝 → 12 犬 |

`game.js` の `KINDS` で、体力・速さ・大きさ・点数を変えられます。

## 調整するときに触る場所

| 変数 | 内容 |
|---|---|
| `FOCAL` / `ZFAR` / `HORIZON` | 遠近の効き方と湧く距離 |
| `RUN_SPEED` | 前へ進む速さ |
| `KINDS` | 敵の性能（弱い敵ほど小さく速く、強い敵ほど大きく遅い） |
| `WAVES` | 時間ごとに出てくる種類 |
| `GATE_OPTIONS` | ゲートの強化内容 |
| `spawnTick()` | 湧く間隔・群れの人数・ボスの周期 |
