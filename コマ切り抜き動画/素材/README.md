# 素材（スクショ）置き場

FANZA等から集めたコマのスクショは、このフォルダに **1本ごとのサブフォルダ** を作って入れてください。

## フォルダの作り方

```
素材/
  001_作品名/
    上.png   ← 上コマ（起）
    下.png   ← 下コマ（転）
  002_作品名/
    上.png
    下.png
```

- 番号は工程表の `管理No` と合わせる
- ファイル名は `上` / `下`（または `1` / `2`）でOK。拡張子は png/jpg どちらでも可

## チャットで送る場合
このチャットに画像を添付して、「管理No・作品名・狙い（バズ/ファン）」を一言添えてください。
こちらで上記フォルダに保存し、スプレッドシートを生成します。

## 注意（コンテンツ基準）
このジャンルの方針どおり、**直接的な性的描写のない（YouTubeガイドライン安全な）コマ**を対象とします。
明らかに露骨なものはスプレッド化・動画化の対象外にします。
