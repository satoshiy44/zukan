# コマ切り抜き動画 運用ドキュメント

漫画コマ切り抜き YouTube Shorts の **台本づくり → 動画制作 → 投稿** を回すためのテンプレート集です。
（直接的なエロ表現は避け、セリフ・テキストで興味を引いて FANZA 作品購入につなげる運用。YouTube ガイドライン順守が大前提）

---

## ジャンルの要点（10万再生超えの共通点）

| 要素 | 正解パターン |
|---|---|
| 画質 | **カラー漫画**（モノクロは伸びにくい） |
| 構成 | **2分割**：上＝起、下＝転 |
| 仕掛け | 上下で「**どっちが〇〇？**」など質問を投げかける |
| 背景 | 暗めの**星空・海**の動画 |
| 見せ方 | 約4秒かけて画像を出す／画像の表示は **0.8秒だけ** |
| 狙い | 短い表示で**一時停止・繰り返し視聴**を誘発 |
| 訴求 | **画像でエロを見せない／セリフで訴求** |

### 伸びる／伸びない

| 伸びる ✅ | 伸びない ❌ |
|---|---|
| カラー | モノクロ |
| 1〜2コマ | — |
| 直接表現はないが**確実にアダルトと想像できる** | 続きが**容易に想像できてしまう**（「この後やりまくるんでしょ」「NTR系ね」） |
| 物語を**予測しやすい（余白がある）** | 予測が**簡単すぎて余白がない** |

→ コツは「**想像はできるが答えは見せない（余白を残す）**」のさじ加減。

## 制作フロー

```
① ネタ（コマ）探し
        ↓
② 工程表テンプレートに 画像・コメントを記入
        ↓
③ 添削依頼①（コマ・コメントのチェック）
        ↓
④ 動画制作
        ↓
⑤ 添削依頼②（完成動画のチェック）
        ↓
⑥ 投稿
```

※ **添削2回**（コマ段階・完成段階）が品質担保の肝。

## スクショ→スプレッド→動画 の協業フロー

```
あなた: FANZA等でコマのスクショを集める（直接描写なしのもの）
        ↓ チャット添付 or 素材/ に配置
私    : 素材を保存 → videos.json に台本下書き → build_spreadsheet.py 実行
        → 「台本スプレッドシート.xlsx」（画像埋め込み＋台本欄）を生成
        ↓
あなた: スプレッドを推敲（質問文・セリフ・オチを調整）→ OK列を埋める
        ↓
私    : OKのものを動画化（※方式は要相談。下記）
```

### スプレッド生成コマンド
```bash
cd コマ切り抜き動画
python3 tools/build_spreadsheet.py tools/videos.json
# → 台本スプレッドシート.xlsx / 台本一覧.md を出力
```
`videos.json` の書式は [`tools/videos.sample.json`](./tools/videos.sample.json) を参照。

### 動画化について（重要）
**Vrew はあなたのPC上のGUIアプリのため、私からは直接操作できません。**
そこで運用は「**土台mp4は私が書き出し → あなたがVrewに読み込んで微調整**」とする。

```bash
cd コマ切り抜き動画
python3 tools/render_video.py tools/videos.json
# → 出力動画/<管理No>.mp4 を書き出し（縦1080x1920）
```
このmp4をVrewにインポートして、テロップ・尺・効果音などの最終調整を行う。

### おすすめの回し方
1. ネタを見つけたら **02 フローチャート**で採用可否を判定
2. 採用したら **03 台本フォーマット**に構成を記入
3. その内容を **01 工程表**に転記して添削依頼 → 制作 → 投稿
