# そっくり額縁

ニコ生ゲーム(ランキングモード)。右上の「おてほん」の絵を見ながら、パーツを額縁の中の同じ場所に置いて、どれだけそっくりにできるかを競います。希望制限時間は85秒。

## あそびかた

- 2枚の絵を、それぞれ30秒で作ります。
  - 1枚目: 野原(春・夏・秋・冬のどれか)
  - 2枚目: おへや
- 右下の置き場から、パーツ(6〜8個)を指でドラッグして額縁の中に置きます。置いたあとも動かせます。額縁の外に出すと置き場にもどります。
- 30秒たつと「こたえあわせ」。おてほんの位置がうすく出て、置いた場所と点線でつながります。
- 1パーツの点は、ずれが0なら1000点、160px以上ずれると0点(ずれが小さいほど急に高くなる)。ほぼピッタリ(10px以内)なら +500点。置いていないパーツは0点。
- おてほんの季節・パーツの数と種類・置き場所は毎回ランダムです(ニコ生では参加者全員が同じおてほん)。

## 開発

```
npm install
npm run build
npm test
npm start          # サンドボックスで遊ぶ
npm run assets     # 画像と音を作り直す
```
