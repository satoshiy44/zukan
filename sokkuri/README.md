# そっくり絵合わせ

ニコ生ゲーム(ランキングモード)。右上の「おてほん」の絵を見ながら、パーツを額縁の中の同じ場所に置いて、どれだけそっくりにできるかを競います。希望制限時間は130秒。

## あそびかた

- 3枚の絵を順番に作ります。だんだん時間がのびて、パーツも増えます。
  - 1枚目: 野原(春・夏・秋・冬のどれか)… 25秒・パーツ5〜7個
  - 2枚目: おへや … 30秒・パーツ6〜8個
  - 3枚目: サーカス(ピエロや動物が芸をするテントの中)… 35秒・パーツ7〜9個
- 右下の置き場から、パーツを指でドラッグして額縁の中に置きます。置いたあとも動かせます。額縁の外に出すと置き場にもどります。
- 30秒たつと「こたえあわせ」。おてほんの位置がうすく出て、置いた場所と点線でつながります。右のパーツ置き場には、パーツごとの「ずれ(mm)」と点数が順番にならび、いちばん下にその絵の点数が出ます。
- 1パーツの点は、ずれが0なら1000点、160px以上ずれると0点(ずれが小さいほど急に高くなる)。ほぼピッタリ(10px以内)なら +500点。置いていないパーツは0点。
- おてほんの季節・パーツの数と種類・置き場所は毎回ランダムです(ニコ生では参加者全員が同じおてほん)。

## 開発

```
npm install
npm run build
npm test
npm start          # サンドボックスで遊ぶ
npm run assets     # 画像と音を作り直す
```
