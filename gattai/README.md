# ぬいぐるみ合体パズル

ニコ生ゲーム(ランキングモード)。5×5のマスにぬいぐるみを置いて、3つつなげて合体・進化させる落ち着いたパズルです。希望制限時間は90秒(遊べるのは約76秒)。自作ゲームパーティー2026秋には応募しない作品です。

## あそびかた

- 空いているマスをタップすると、「いまの」ぬいぐるみを置きます。
- 同じぬいぐるみが3つ以上つながると合体して、置いたマスに1つ上のぬいぐるみができます。4つ以上なら2つ上に進化します。
- 合体でできたぬいぐるみが、また隣と3つつながると **れんさ**。れんさするほど点が大きくなります(2れんさ目は1.5倍、3れんさ目は2倍…)。
- 「ほかん」をタップすると、いまのぬいぐるみをしまっておけます。もう一度タップで入れかえ。
- 虹色の星は「なんでも」。置いたマスで合体できる、いちばん高いぬいぐるみに変身します。
- 金のくま(レベル9)を3つつなげると **だいばくはつ**。まわり3×3を吹き飛ばして大量得点。
- 作ったぬいぐるみが大きくなるほど、出てくるぬいぐるみも大きくなります。盤面に取り残された小さいぬいぐるみも、ときどき出てくるので片づけられます。
- マスが全部うまると「ぎゅうぎゅう!」。小さいぬいぐるみから片づけられます。
- 出てくるぬいぐるみの順番は参加者全員共通です。

| レベル | ぬいぐるみ | できたときの点(3つ合体) |
| --- | --- | --- |
| 1 | ひよこ | - |
| 2 | こぶた | 20 |
| 3 | ペンギン | 60 |
| 4 | ねこ | 180 |
| 5 | いぬ | 500 |
| 6 | くま | 1500 |
| 7 | パンダ | 4000 |
| 8 | ユニコーン | 10000 |
| 9 | 金のくま | 25000 |
| - | だいばくはつ | 50000 |

## 開発

```
npm install
npm run build
npm test
npm start          # サンドボックスで遊ぶ
npm run assets     # 画像と音を作り直す(ぬいぐるみの絵は crane/image から作る)
```
