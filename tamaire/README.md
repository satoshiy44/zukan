# ころころ玉入れ(運動会ピンボール)

ニコ生ゲーム(ランキングモード)向けの自作ゲームです。「自作ゲームパーティー2026秋」の『ノンジャンル』部門への応募を想定しています。

## あそびかた

- 画面を押すと、発射台の向きが決まり、玉の飛ぶ道すじが点線で出ます。指を動かしてねらい、**はなすと発射**します(タップだけでも、その方向に撃てます)。
- 玉は紅白の玉(ピン)にはね返りながら落ちていきます。当たった玉は光り、玉が下に落ちると消えます。
- **赤い玉を全部たおすと「種目クリア」**で、次の配置(種目)に進みます。
- 1回の発射でたくさん当てるほど倍率が上がります(5れんさで×2 … 20れんさで×5)。
- 下で左右に動く**玉入れかごに入ると、その1投の点が2倍**になります。
- 金メダルは大当たり(1000点)です。
- **ラスト12秒は「大玉ころがし」**で、玉が大きくなり、得点も2倍になります。
- 玉は何回でも撃てます。ゲームオーバーはありません。

| 玉 | 点数(×れんさ倍率) |
| --- | --- |
| 白い玉 | 20 |
| 赤い玉 | 200 |
| 金メダル | 1000 |
| 種目クリア | 3000(種目が進むごとに +1500) |

ピンの配置は共通乱数(`randomSeed`)から作るので、同じ回の参加者は全員同じ配置で競います。かごの動きも全員同じです。

## 開発

```bash
npm install          # 依存を入れてビルド
npm start            # サンドボックスで起動
npm test             # headless-akashic で最後まで遊ぶテスト
npm run assets       # 画像と効果音を作り直す
npm run export-zip   # 投稿用の game.zip を作る (ネットにつながったPCで)
```

- 画像は `tools/gen-images.js`、音は `tools/gen-audio.py` で作っています。外部素材は使っていないので、権利表記は不要です。たぬきの絵は「おいもチキン」と共通です。
- 解像度 1280x720 / 30fps / 希望制限時間 80秒(説明4秒 + プレイ66秒 + 結果)。
- 玉の動き(重力、ピンと壁のはね返り)は自前で計算しています。1フレームを5回に分けて計算し、すり抜けを防いでいます。
