# 囲んで鍵探し

ニコ生ゲーム(ランキングモード)。1万枚のコインの中にまぎれた1本の鍵を、指で丸く囲んでしぼりこんでいくゲームです。希望制限時間は45秒(遊べるのは30秒)。

## あそびかた

- 四角の中に、コインが1万枚と鍵が1本。鍵はコインと同じ見た目なので、目では見つけられません。
- 指で丸く囲むと、その中に鍵があるか判定されます。
  - **入っていた(○)**: 囲んだコインだけが新しい四角に移り、候補が減ります。
  - **入っていなかった(×)**: 何も変わらず、少しのあいだ線を引けません。
- 小さく囲めば一気にしぼれますが、はずれやすい。大きく囲めば安全ですが、あまり減りません。
- 30秒で「1 / x」の x をどこまで小さくできるかを競います。
- 鍵1本だけになったら「見つけた!」。そのまま2周目として、また1万枚から始まります。
- 点数は「見つけた鍵の本数 × 100000 + いまの周の 100000 ÷ x」。
- 鍵の場所とコインの並びは、参加者全員共通の乱数で決まります。

## 開発

```
npm install
npm run build
npm test
npm start          # サンドボックスで遊ぶ
npm run assets     # 画像と音を作り直す
```

コイン1万枚は1枚のサーフェスにまとめて描いています(スプライト1万個だと重いため)。
