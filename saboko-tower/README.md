# さぼこタワー

さぼこを積み上げて高さを競うゲームです。
`index.html` をブラウザで開くだけで動きます（サーバ不要・オフライン可）。

## 遊び方

- 左右に動かしてクリック／タップで置く（`←` `→` と `Space` でも操作可）
- 当たり判定は**上下が平行な台形**です。幅は絵ごとに違うので、置き方の相性はあります
- 積み上がりが高くなるとカメラが上へついていきます。100cmごとに目盛りが出ます
- 自己最高の高さには赤い線が引かれます
- 画面上の**星3つ**が残機です。横に落とすと1つ減り、3つなくなるとゲームオーバー

## 素材はスイカゲームと共用

形データ（`../assets/shapes.js`）と物理エンジン（`../vendor/`）を
そのまま使っています。画像を差し替えるときは、リポジトリのルートで
`npm run build:assets` を実行すれば、こちらにも反映されます。

面積が揃うように拡縮しているので、どれを引いても積みやすさが極端には変わりません。

## 当たり判定を台形にしている理由

最初はスイカゲームと同じくシルエットそのままを当たり判定にしていましたが、
凸凹が噛み合わず、いくら置いても積み上がりませんでした（自動プレイで58cm）。

上下が平行な台形に置き換えると、接する面が必ず水平になるので積めます。
台形の幅は**絵の実際の輪郭を上下2か所で測って**決めているので、見た目と
当たり判定の差は小さいままです。細くなりすぎると乗せる場所が無くなるため、
上下の辺は絵の幅の55%を下限にしています。

同じ自動プレイで58cm → 225cm になりました。
`index.html?debug` で当たり判定の台形を重ねて確認できます。

## 作りのポイント

**カメラは世界を動かさない。** 描くときに `camera` ぶん下へずらすだけなので、
物理側は高さのことを何も気にしなくて済みます。

**構える高さは積み上がりに追従させています。** 画面の固定位置から落とすと、
序盤は高い位置から落とすことになり、その衝撃だけで土台が崩れてしまいます。
先端の少し上（`HOLD_GAP`）で構えるようにして解決しました。

**崩れたときの残機。** 崩壊すると何個もまとめて落ちるので、そのたびに残機を
減らすと一瞬で終わってしまいます。短い間に続けて落ちたぶんは「1回の崩壊」として
数えています。

## ファイル構成

```
index.html                画面
style.css                 見た目
game.js                   ゲーム本体
audio.js                  効果音・合成BGM
assets/audio/             BGMを置く場所
assets/sounds.js          BGMを埋め込んだもの（自動生成）
tools/build-audio.mjs     assets/audio の音源から sounds.js を作る
tools/bundle.mjs          全部を1枚のHTMLにまとめる
```

## 音

BGMは `assets/audio/` に曲を置いて `npm run tower:audio` を実行すると差し替わります。
置かなければ合成した穏やかなループが鳴ります。
**積むたびに音が上がっていく**ので、伸びている手応えが音でも分かります。

## 調整するときに触る場所

| 変数 | 内容 |
|---|---|
| `PIECE_R` | さぼこの大きさ（面積の基準） |
| `PLATFORM_W` | 土台の幅。狭いほど難しい |
| `HOLD_GAP` | 積み上がりからどれだけ上で構えるか。大きいほど落下の衝撃が強い |
| `LIVES` | 星の数（残機） |
| `PIECE_OPTS` の `friction` | 滑りやすさ。下げると崩れやすくなる |
| `TOP_SAMPLE` / `BOTTOM_SAMPLE` | 台形の幅を絵のどの高さで測るか |
| `MIN_EDGE_RATIO` | 台形の上下の辺の最小幅（絵の幅に対する比） |
| `PX_PER_CM` | 高さの cm 表記の換算 |
