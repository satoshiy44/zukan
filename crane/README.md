# クレーン取り放題

ニコ生ゲーム(ランキングモード)。何回やってもタダの3Dクレーンゲームで、山積みのぬいぐるみを取りまくって点数を競います。希望制限時間は75秒(遊べるのは約61秒)です。

## あそびかた

- **① 長押し**している間、クレーンが右へ動きます。はなすと止まります。
- **② もう一度長押し**している間、クレーンが奥へ動きます。はなすとアームが下りて、ぬいぐるみをつかみます。
- アームの真下には赤い丸の目印が出ます。右下の「上から見た図」でも位置を確認できます。
- とりだし口まで運べたらゲット。大きいぬいぐるみほど高得点ですが、真ん中をつかまないと落ちやすいです。
- アームが山に突っ込むと、まわりのぬいぐるみがはじかれて転がります。とりだし口に転がり込んでもゲット。
- 1回で2こ以上取ると、2こ目は1.5倍、3こ目は2倍…と点が上がります。
- 続けて取れると「れんぞく」で倍率アップ(最大×3)。取れなかったら倍率は元に戻ります。
- アームが戻っている間に押しておくと、着いたらすぐ次の①が始まります。
- ぬいぐるみが減ると上から補充されます。ぬいぐるみの種類と置き場所は参加者全員共通です。
- ラスト10秒は得点2倍、ぬいぐるみも大量補充。

| ぬいぐるみ | 大きさ | 点 |
| --- | --- | --- |
| ひよこ・こぶた・ペンギン・かえる・ハムスター | 小 | 100 |
| うさぎ・ねこ・いぬ・ひつじ・きつね | 中 | 250 |
| くま・ライオン・ぞう | 大 | 600 |
| でかパンダ・でかクジラ | 特大 | 1500 |
| 金のくま | レア | 2000 |
| ユニコーン | 超レア | 3000 |

最初から約170こが山になっています。高得点の大きいぬいぐるみやレアほど右(とりだし口から遠い所)に、小さいぬいぐるみほど左に置かれます。

## ホールド力

つかむたびに、アームの「ホールド力」が3〜10のどれかになります(アームの横に表示)。3〜7がよく出て、8〜10はたまにしか出ません。
ホールド力が低いほど、運んでいる途中や上で「ガクッ」と止まったときに落ちやすくなります。
つかむ位置がずれているとき、大きいぬいぐるみのときも落ちやすくなります。
ホールド力の順番と、落ちるかどうかのくじは参加者全員共通です。

## リアルな動き(擬似3D)

Akashic Engine には3D描画がないので、遠近法で奥行きのある画面を描いています。

- クレーンは加速・ブレーキがあり、アームは振り子のようにゆれます(ゆれた分、つかむ位置もずれます)。
- つかんだ瞬間に一瞬止まり(ヒットストップ)、ゲットすると画面がゆれて、点数がカウントアップします。
- 上まで上がると「ガクッ」と止まり、ホールド力しだいでここで落ちることもあります。
- 落ちたぬいぐるみは、アームの勢いのまま飛んで、跳ねて、山の上を転がります。

## 開発

```
npm install
npm run build
npm test
npm start          # サンドボックスで遊ぶ
npm run assets     # 画像と音を作り直す
```

画像は `tools/gen-images.js`、音は `tools/gen-audio.py` で作っています(すべて自作)。
