# クレーン取り放題

ニコ生ゲーム(ランキングモード)。何回やってもタダの3Dクレーンゲームで、カプセルを取りまくって三角くじの点数を競います。

## あそびかた

- **① 長押し**している間、クレーンが右へ動きます。はなすと止まります。
- **② もう一度長押し**している間、クレーンが奥へ動きます。はなすとアームが下りて、カプセルをつかみます。
- アームの真下には赤い丸の目印が出ます。右下の「上から見た図」でも位置を確認できます。
- とりだし口まで運べたらゲット。カプセルが開いて、中の**三角くじ**で等級と点数が決まります。
- つかむ位置がずれていると、運ぶ途中や、上で「ガクッ」と止まったときに「ぽろっ」と落ちます。
- 1回で2こ以上取ると、2こ目は1.5倍、3こ目は2倍…と点が上がります。
- 続けて取れると「れんぞく」で倍率アップ(最大×3)。取れなかったら倍率は元に戻ります。
- カプセルが減ると上から補充されます。カプセルの色・置き場所・中のくじは参加者全員共通です。
- ラスト10秒は得点2倍、カプセルも大量補充。

| カプセル | 出やすさ | 中のくじ |
| --- | --- | --- |
| 黒 | たくさん | 5等〜2等(ほとんど5等・4等) |
| 金 | そこそこ(5こに1こ) | 3等〜特賞。少し重くて、真ん中をつかまないと落ちやすい |

| 等級 | 点 |
| --- | --- |
| 特賞 | 2000 |
| 1等 | 1000 |
| 2等 | 500 |
| 3等 | 300 |
| 4等 | 200 |
| 5等 | 100 |

## リアルな動き(擬似3D)

Akashic Engine には3D描画がないので、遠近法で奥行きのある画面を描いています。

- クレーンは加速・ブレーキがあり、アームは振り子のようにゆれます(ゆれた分、つかむ位置もずれます)。
- 上まで上がると「ガクッ」と止まり、つかみがギリギリのカプセルはここで落ちます。
- 落ちたカプセルは、アームの勢いのまま飛んで、跳ねて、山の上を転がります。

## 開発

```
npm install
npm run build
npm test
npm start          # サンドボックスで遊ぶ
npm run assets     # 画像と音を作り直す
```

画像は `tools/gen-images.js`、音は `tools/gen-audio.py` で作っています(すべて自作)。
