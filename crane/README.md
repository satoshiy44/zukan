# クレーン取り放題

ニコ生ゲーム(ランキングモード)。何回やってもタダのクレーンゲームで、制限時間内に景品を取りまくって点数を競います。

## あそびかた

- 画面を**長押し**している間、クレーンが右へ動きます。**はなす**とアームが下りて、景品をつかみます。
- 景品をとりだし口まで運べたらゲット。つかむ位置がずれていると、運ぶ途中で「ぽろっ」と落ちます。重い景品ほど、真ん中をつかまないと落ちます。
- 景品の山がくずれて、仕切りを越えてとりだし口に入ってもゲット(ころがりゲット)。
- 1回で2こ以上取ると、2こ目は1.5倍、3こ目は2倍…と点が上がります。
- 続けて取れると「れんぞく」で倍率アップ(最大×3)。取れなかったら倍率は元に戻ります。
- 景品が減ると上から補充されます。補充される景品の順番は参加者全員共通です。
- ラスト10秒は得点2倍、景品も大量補充。

| 景品 | 点 | つかみやすさ |
| --- | --- | --- |
| あめ | 30 | さわればつかめる |
| おかし | 80 | やさしい |
| ぬいぐるみ | 200 | ふつう |
| でかぐるみ | 600 | 真ん中をねらう |
| 金のたぬき | 1500 | 真ん中をねらう |

## 開発

```
npm install
npm run build
npm test
npm start          # サンドボックスで遊ぶ
npm run assets     # 画像と音を作り直す
```

画像は `tools/gen-images.js`、音は `tools/gen-audio.py` で作っています(すべて自作)。
